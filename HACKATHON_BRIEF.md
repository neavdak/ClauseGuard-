## Hard technical requirements
1. Runtime call to **Nebius Token Factory** inference API (OpenAI-compatible), OR deployed/run on **Nebius AI Cloud** (Serverless Endpoints, Serverless Jobs, DevPods).
2. Use **≥1 NVIDIA open-source model**: Nemotron 3 Nano (30B MoE, ~3B active — cheap/fast), Nemotron 3 Super (120B hybrid Transformer-Mamba MoE, 1M ctx — agents), Nemotron 3 Ultra (deep reasoning), Nano 2 VL (vision), GROOT/Cosmos/Sonic (physical AI).
3. Model routing pattern encouraged: Ultra for hard reasoning, Nano/Super for everyday calls (latency + credits).
4. Bonus integrations: **Tavily** search ($3,000 Best Use prize), Token Factory Sandboxes (code execution), Serverless Endpoints/Jobs.

## Tracks
1. **Coding & Agentic Engineering** — agents that write/run/test code in Token Factory Sandboxes.
2. **Best Apps & Agents** — any genuinely usable app/copilot/self-running workflow on Nemotron + Token Factory.
3. **Personal AI** — always-on private assistant: persistent memory, reusable skills, user-chosen tools (NemoClaw, OpenShell, Hermes Agent, Nebius Serverless).
4. **Physical AI** — robotics/IoT/edge; video needs ≥1 min of real hardware (or modules) in action; demo URL waived.

## Judging criteria
1. **Technological Implementation** — build quality + effective use of Nebius & Nemotron
2. **Design** — complete coherent product experience, not a PoC
3. **Potential Impact** — credible real problem/audience, demonstrated solution
4. **Quality of Idea** — creative, non-obvious use; problem-space understanding

## Rules notes
- Individuals OR teams; one person submits as representative.
- Multiple submissions allowed if substantially different.
- Must be original work, entrant-owned IP; OSS dependencies must comply with licenses.
- No project developed with funding/contract from Nebius/NVIDIA/Devpost.
- Materials in English (or English translations provided).
- Excluded: Brazil, Quebec, Russia, Crimea, Cuba, Iran, North Korea, comprehensively sanctioned countries.
